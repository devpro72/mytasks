✦ وضع داكن وأنيق:

## 2. لقطات الشاشة — المتطلبات التقنية (macOS)

| المعيار | القيمة |
|---|---|
| الحد الأدنى | **لقطة واحدة على الأقل** (نوصي بـ 6–8) |
| الأبعاد المقبولة | **1280×800** (الموصى بها) أو 1440×900 أو 2560×1600 أو 2880×1800 |
| الصيغة | PNG أو JPEG |
| الحد الأقصى | 10 لقطات |
| طريقة الالتقاط | ⌘⇧4 ثم المسافة لالتقاط نافذة كاملة — أو لقطة شاشة كاملة داخل نافذة بدقة 1280×800 |
| قاعدة Apple (2.3.3) | يجب أن تُظهر اللقطة التطبيق الحقيقي دون تجريج خداعي |

### اللقطات المقترحة مع العنوان العربي فوق كل لقطة:

1. **«يومك كله في نظرة واحدة»** — لوحة الاستقبال (المهام البارزة + المستحقة قريبًا)
2. **«اسحب مهامك بين الأعمدة بسهولة»** — لوحة كانبان (تطوير / تحت التنفيذ / مكتملة)
3. **«ملاحظاتك بالعربية كما تريد»** — وحدة الملاحظات مع وضوح RTL والمجلدات
4. **«تذكير لا يُنسى»** — قائمة التذكيرات أنيقة مع التنبيهات
5. **«ملاحظة سريعة بـ ⌘O وقت ما تشاء»** — النافذة العائمة
6. **«علاماتك المرجعية بضغطة»** — العلامات المرجعية مع أيقونات التصنيف
7. **«مزامنة آمنة عبر iCloud»** — شاشة الإعدادات مع بطاقة التخزين السحابي
8. **«نسخة احتياطية بضغتين»** — بطاقة النسخ الاحتياطي (تصدير/استيراد JSON)
9. **«وضع داكن أنيق»** — أي شاشة بمظهر داكن

💡 **كيف تُضيف العنوان العربي فوق اللقطة بسهولة:**
افتح **Keynote** ملفًا جديدًا بحجم شريحة 1280×800 — ضع عنوانًا عربيًا أعلى الشريحة ولقطة التطبيق أسفلها — ثم «تصدير → صورة». كرر لكل لقطة.

## 3. الخصوصية / App Privacy (تُسألها بعد رفع البناء)

القاعدة: التطبيق **لا يجمع بيانات** خارج حساب المستخدم الخاص (CloudKit):
- «هل تجمع أي بيانات من هذا التطبيق؟» ← **لا**
- وبذلك تظهر شارة «لا تُجمع البيانات» في صفحة المتجر — تعزز ثقة المستخدم.
